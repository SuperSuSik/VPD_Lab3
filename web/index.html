ЛР3. Валидация строк, регулярные выражения и URI

Учебная форма проверяет строковые данные без перезагрузки страницы. Подсветка неверного поля и текст ошибки обновляются на месте.

1. Форма

2–4 слова на кириллице, допускается дефис.
Шаблон: М3О-три цифрыБВ-две цифры; М и О кириллические.
Один учебный формат: +7 (999) 123-45-67.
Упрощённое правило, не полная реализация RFC 5322.
Формат YYYY-MM-DD + проверка существования даты.
Только http/https; проверка штатным new URL().

2. Разбор URI: регулярное выражение и штатный URL

Учебная регулярка разбирает схему, authority, путь, запрос и фрагмент. Штатный new URL() дополнительно декодирует query-параметры. Для реальных URI нужен специализированный парсер: он учитывает IPv6, userinfo, IDN, percent-encoding и десятки краевых случаев.

3. Percent-encoding, HTML-сущности и Base64

Это три разных механизма и три разных контекста:

  • percent-encoding — кодирование байтов внутри URI;
  • HTML-сущности — синтаксис HTML-документа для кодовой точки;
  • Base64 — представление произвольных байтов ASCII-текстом.
