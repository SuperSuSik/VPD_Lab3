UTF-8 переменной длины: ASCII — 1 байт, кириллица — 2, иероглифы — 3.
UTF-16: BMP-символы — 2 байта (суррогатная пара — 4).
UTF-32: всегда 4 байта на скалярное значение; цена — память.

==============================================================================
2.6. BOM и порядок байтов в UTF-32
==============================================================================
utf-32    : FF FE 00 00 27 59 00 00 66 5B 00 00
utf-32-le : 27 59 00 00 66 5B 00 00
utf-32-be : 00 00 59 27 00 00 5B 66
sys.byteorder = little
BOM: FF FE 00 00 — UTF-32 little-endian (BOM присутствует).
BOM сообщает порядок 32-битных кодовых единиц. Явные utf-32-le/be
BOM не добавляют: порядок уже задан именем кодировки.

==============================================================================
2.7. История одного байта: 0xB8
==============================================================================
data = B8
cp1251: 'ё', U+0451 (CYRILLIC SMALL LETTER IO)
UTF-8 error: 'utf-8' codec can't decode byte 0xb8 in position 0: invalid start byte

Буква «ё» в трёх представлениях:
  cp1251    : B8
  UTF-8     : D1 91
  UTF-32 LE : 51 04 00 00

0xB8 — однобайтовый код «ё» только в Windows-1251. В UTF-8
байт 0xB8 — continuation-байт (10xxxxxx), а не начало символа;
поэтому отдельно он не образует корректную UTF-8-последовательность.
Корректная UTF-8-запись «ё»: D1 91 (два байта).

==============================================================================
2.9. Гомоглифы: кириллические М/О и латинские M/O
==============================================================================
кириллица: М3О-304БВ-26
  первые 3 кода: U+041C, U+0033, U+041E
  имена:         CYRILLIC CAPITAL LETTER EM, DIGIT THREE, CYRILLIC CAPITAL LETTER O
  UTF-8:         D0 9C 33 D0 9E 2D 33 30 34 D0 91 D0 92 2D 32 36
латиница : M3O-304БВ-26
  первые 3 кода: U+004D, U+0033, U+004F
  имена:         LATIN CAPITAL LETTER M, DIGIT THREE, LATIN CAPITAL LETTER O
  UTF-8:         4D 33 4F 2D 33 30 34 D0 91 D0 92 2D 32 36

строки равны: False
равны после NFKC: False
NFKC не устраняет гомоглифы: это разные кодовые точки с похожими
начертаниями. Для безопасности нужны политики смешанных алфавитов,
confusable-проверки и ограничения на домены/идентификаторы.

==============================================================================
2.11. HTML: один символ в трёх представлениях
==============================================================================
обычный символ: ё
HTML dec:       &#1105;
HTML hex:       &#x451;
кодовая точка:  U+0451 = 1105
UTF-8:          D1 91
Все три HTML-записи ссылаются на один и тот же U+0451.

Ручной декодер проверил UTF-8 без сторонних Unicode-библиотек.
Ограничения приблизительного счётчика графем: не реализованы все
правила UAX #29 (флаги, keycap, модификаторы тона кожи). Для
продакшена нужен специализированный segmentation API.

Python len(str) считает кодовые точки, len(bytes) — байты, а
визуальные глифы требуют анализа графемных кластеров.
